# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in OASGate or its distribution artifacts, please use GitHub's [private Report a vulnerability form](https://github.com/AlloysP/oasgate-releases/security/advisories/new).

Do not disclose vulnerabilities, exploit details, credentials, private API specifications, sensitive logs, or other confidential information in public issues, discussions, or pull requests.

Maintainers will make a best-effort acknowledgement of private vulnerability reports within **7 calendar days**. This is not a guaranteed response, remediation deadline, or service-level agreement. Disclosure timing is coordinated case by case.

## Non-security issues

For ordinary bugs or questions, use [GitHub Issues](https://github.com/AlloysP/oasgate-releases/issues) with only public, synthetic, sanitized, or placeholder-only information.

Do not include private specifications, customer data, credentials, internal hostnames, sensitive logs, or identifying screenshots.

This policy establishes reporting channels; it does not announce a publicly supported or available OASGate release.
